## 2. Deploying Backend to Render / Railway

### Render Blueprint Deployment (`render.yaml`):
1. Connect your GitHub repository to Render.
2. Render automatically discovers [`render.yaml`](file:///Users/devanshjain06/Desktop/aictr/render.yaml).
3. The blueprint provisions:
   - Web Service `drishti-x-backend` (Python 3.11 runtime)
   - Managed PostgreSQL database `drishti-x-db`
4. Set Environment Variables in Render Dashboard:
   - `SECRET_KEY`: Automatically generated by Render
   - `FRONTEND_URL`: Set to your deployed Vercel domain (e.g. `https://drishti-x.vercel.app`)
   - `GOOGLE_CLIENT_ID`: Your Google OAuth Client ID

### Railway Deployment:
```bash
# Using Railway CLI
railway login
railway init
railway add --plugin postgresql
railway up
```

---

## 3. Deploying Frontend to Vercel

1. Import the repository into your Vercel Dashboard.
2. Set Root Directory to: `frontend`
3. Configure Environment Variables in Vercel:
   - `NEXT_PUBLIC_API_URL`: `https://your-backend.onrender.com`
   - `NEXT_PUBLIC_GOOGLE_CLIENT_ID`: Your Google OAuth Client ID
4. Click **Deploy**. Vercel executes `npm run build` using the configured webpack pipeline.
